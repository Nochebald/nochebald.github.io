# Video previews

Place only **small portfolio preview clips** in this folder.

Suggested names (already referenced by `index.html`):

- `peripheral-nerve-preview.mp4`
- `drg-preview.mp4`

Recommendations:

- MP4 / H.264 is the simplest browser-compatible format.
- Keep previews short (for example 10–30 seconds).
- For unpublished work, use reduced resolution and consider a subtle watermark.
- Do not upload raw stacks, full-resolution unpublished data, or confidential material.
- Do not use Git LFS for files that must be served directly by GitHub Pages.
- If videos become large, host them elsewhere and embed/link them from the site.
